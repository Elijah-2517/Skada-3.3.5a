# Правила репозитория

- Каждый коммит, который добавляет или меняет функцию, обязан в том же коммите обновить `README.md`: раздел «Изменения», количество тестов в «Проверке», при необходимости «Ограничения». Если коммит не меняет поведение (тесты, служебные файлы), README не трогать.
- В `README.md` не должно быть упоминаний ассистентов, нейросетей и ИИ. Текст установки пишется как точная пошаговая инструкция: что скачать, куда положить, как проверить результат и чего не делать.
- В релизный архив `Skada-3.3.5a.zip` входят только три папки: `Skada`, `SkadaStorage`, `SkadaImprovement`.
- Номер версии (`Skada/Skada.toc`) повышается на каждый выпуск; релиз называется `v1.8.88-netic.1-fixes.N`.
- Перед коммитом: `python -I -m unittest discover -s tests -p "skada_*.py"`. Для новой логики добавляется тест.
