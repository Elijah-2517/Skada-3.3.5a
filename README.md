# Skada для WoW 3.3.5a

Модифицированная сборка [Skada-WoTLK](https://github.com/bkader/Skada-WoTLK) на основе версии 1.8.87. Интерфейс клиента: 30300.

## Изменения

- Полезный урон по валькирам на Личе в героическом режиме ограничен первыми 50% здоровья.
- Если максимальное здоровье валькиры появляется позже, полезные значения прежних ударов пересчитываются с сохранением игроков, заклинаний и целей.
- Урон по слизнюкам Гниломорда исключён из полезного урона; для принцев учитывается активная цель.
- Урон змей охотника объединяется с владельцем при наличии данных о призыве.
- Исправлены сохранение выбранного боя, возврат после боя, автоостановка при вайпе и суммы урона с поглощениями.
- Расчёт специальных целей выполняется один раз на событие, независимо от числа записываемых фаз.

## Установка

1. Скачайте архив через **Code → Download ZIP** и распакуйте его.
2. Скопируйте папку `Skada` в `Interface/AddOns/`, заменив существующую Skada. Перед заменой сохраните резервную копию.
3. При необходимости скопируйте также `SkadaStorage` и `SkadaImprovement`. Это дополнительные модули; они отключены по умолчанию.
4. Перезапустите клиент или выполните `/reload`.

В `Interface/AddOns/Skada/` должен находиться файл `Skada.toc`. Папку репозитория целиком в AddOns помещать не нужно.

Изменения расчёта относятся к новым боям. Старые сохранённые сегменты автоматически не пересчитываются.

## Почему окно переключается на текущий бой

Автоматический переход на текущий бой при начале сражения — штатная внутренняя настройка Skada, а не баг. Если эта настройка включена, окно переключается на новый бой, даже когда до этого был открыт сохранённый бой с боссом.

Чтобы отключить такое поведение:

1. Откройте настройки командой `/skada config`.
2. Перейдите в **Окна → нужное окно → Дополнительные → Смена режима**.
3. Снимите галочку **«Авто переход к текущему»**.
4. Проверьте **«Режим битвы»**: выбранный здесь режим тоже переключает окно на текущий бой при входе в бой. Чтобы сохранить выбранный старый бой, установите отсутствие режима — **«Нет» / None**.

Эти параметры задаются отдельно для каждого окна. **«Возврат после боя»** возвращает прежний сегмент и режим после переключения через «Режим битвы»; сам переход в начале боя эта галочка не отключает. **«Режим вайпа»** может отдельно переключать окно на текущий сегмент после вайпа.

Исправления навигации по сохранённым боям в этой сборке сохраняют выбранный сегмент при изменении истории. Настроенное автоматическое переключение в начале боя продолжает работать согласно указанным параметрам.

## Ограничения

Точный порог валькир требует хотя бы одного достоверного значения максимального здоровья от клиента. Пока оно недоступно, оба режима показывают согласованный предварительный результат. Если здоровье так и не получено, точный порог восстановить невозможно.

Привязка змей требует данных о владельце. Расчёт ресурсных фаз оценивает расход ресурса по боевому урону; точный расход маны зависит от серверных событий. Поведение необходимо проверить на конкретном сервере; испытания в настоящем рейде для этих правок пока не выполнены.

## Проверка

Регрессия: 41 тест на Lua 5.1, включая пороги здоровья, фазы, поглощения, атрибуцию питомцев, сброс статистики и переключение сегментов.

```sh
python -m pip install -r tests/requirements.txt
python tests/skada_regression.py
```

Используется Lua 5.1 из пакета `lupa`. Синтаксис 110 Lua-файлов сборки также проверен на Lua 5.1.
